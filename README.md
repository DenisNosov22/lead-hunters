# Lead Hunters Figma React

## Як подивитись сайт

Node.js вже встановлений локально в папку `.tools`, системно встановлювати його не потрібно.

### Git Bash

```bash
cd /d/portfolio/figma_test
bash dev.sh
```

Після запуску відкрий:

```text
http://127.0.0.1:5173/
```

### PowerShell або CMD

Відкрий термінал у папці проєкту:

```powershell
cd D:\portfolio\figma_test
```

Запусти:

```powershell
.\dev.cmd
```

Після запуску відкрий:

```text
http://127.0.0.1:5173/
```
